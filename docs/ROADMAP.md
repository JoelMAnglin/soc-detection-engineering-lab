# Production hardening roadmap

1. Add authenticated ingestion with replay protection and schema registry.
2. Validate CrowdStrike, Proofpoint, Wiz, and Zscaler adapters against authorized tenants.
3. Deploy Splunk content to a development search head and measure precision/latency.
4. Add case-management integration in draft-only mode.
5. Add immutable evidence/audit storage and RBAC.
6. Add Sigma mappings, CI query regression tests, and detection-as-code releases.
7. Add safe LLM enrichment with citations, prompt-injection defenses, redaction, budgets, and human approval.
8. Add response orchestration only after change control, least privilege, rollback, and independent validation.
